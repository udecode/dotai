# dotai

AI-powered development template with Claude Code, Codex, and Cursor integration.

## What is this?

A project template that combines powerful AI development tools:

- [**Claude Code**](https://docs.anthropic.com/en/docs/claude-code/overview) - Anthropic's CLI (Sonnet 4.5) with Flashbacker session continuity
- [**Codex**](https://agents.md/) - CLI AI assistant using AGENTS.md for focused, context-aware responses
- [**Cursor**](https://www.cursor.com/) - AI-powered IDE for manual code review (optional)

## Getting Started

### Prerequisites

Install [Flashbacker](https://github.com/agentsea/flashbacker) (once per machine):

```bash
bash .claude/flashback/scripts/install-flashbacker.sh && source ~/.zshrc
```

### Quick Start

1. **Install dependencies & generate context:**

   ```bash
   pnpm install
   pnpm ctx --init
   ```

2. **Launch both CLIs in separate terminals:**

   ```bash
   # Terminal 1: Claude Code (Sonnet 4.5)
   claude

   # Terminal 2: Codex
   codex
   ```

3. **Work in parallel:**
   - Claude Code: Quick iterations, UI work, continuous dev
   - Codex: Long-running tasks, backend, deep debugging

## How It Works

### Context Files

| CLI         | Context Files                                       | Hooks Support                            |
| ----------- | --------------------------------------------------- | ---------------------------------------- |
| Claude Code | `CLAUDE.md` + `CLAUDE.local.md` (auto-generated)    | ✅ SessionStart (Flashbacker auto-loads) |
| Codex       | `AGENTS.md` (auto-generated)                        | ❌ No hooks (manual Flashbacker)         |
| Both        | Generated by `pnpm ctx` from `.claude/context.json` | Reload: `/clear` or `/new`               |

**Always included:** `project-status.md`, `app-design-document.md`, `tech-stack.md` (set in context.json)

### Context Switching Workflow

```bash
# 1. Generate new context for a task
pnpm ctx frontend  # or: backend, app, custom rules

# 2. Reload both CLIs
# Claude Code: /clear
# Codex: /new
```

## Commands

| Command                  | Description                                    | Category |
| ------------------------ | ---------------------------------------------- | -------- |
| `pnpm ctx`               | Generate AGENTS.md with task-specific rules    | Context  |
| `/create-prd`            | Create PRD without questions                   | Docs     |
| `/create-prd-interactive`| Create PRD with clarifying questions           | Docs     |
| `/parse-prd`             | Parse PRD into implementation checklist        | Docs     |
| `/create-app-design`     | Generate app design document                   | Docs     |
| `/update-app-design`     | Update app design document                     | Docs     |
| `/create-tech-stack`     | Generate tech stack documentation              | Docs     |
| `/update-tech-stack`     | Update tech stack documentation                | Docs     |
| `/create-rule`           | Create new Cursor rule file                    | Docs     |
| `/update-rule`           | Update existing Cursor rule                    | Docs     |
| `/pr`                    | Create PR, auto-review, manage workflow        | Git      |
| `/draft-pr`              | Create draft PR without review                 | Git      |
| `/fb:how`                | Plan implementation before coding              | Planning |
| `/fb:working-plan`       | Update development roadmap                     | Planning |
| `/fb:save-session`       | Capture session insights                       | Planning |
| `/debug`                 | Systematic debugging process                   | Support  |

**Context:** `pnpm ctx frontend` · `pnpm ctx backend` · `pnpm ctx app` · `pnpm ctx <rules...>`

See `/ctx` for detailed rule selection guidance.

## Choosing Your Tool

| Tool            | Best For                                    | Limitations                                    |
| --------------- | ------------------------------------------- | ---------------------------------------------- |
| **Claude Code** | Quick iterations, UI, general coding        | Requires `/clear` after context updates        |
| **Codex**       | Long-running tasks, backend, deep debugging | Worst CLI UX, no hooks, manual session saves   |
| **Cursor**      | Manual code review with visual diffs        | Most expensive, slower with long conversations |

## Flashbacker Integration

Session continuity for Claude Code via hooks (`.claude/settings.json`).

**Key Commands:**

- `/fb:working-plan` - Update development roadmap
- `/fb:save-session` - Capture insights before breaks
- `/fb:how "task"` - Validate understanding before coding

**Auto-magic:**

- SessionStart hook loads `WORKING_PLAN.md` on startup/after compaction
- Chat history survives auto-compacts

**Codex:** No hooks - manually run Flashbacker commands and mention saved context after `/new`
